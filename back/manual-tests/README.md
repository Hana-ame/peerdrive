# 手动测试

> ① 填写测试目的和步骤 → ② 评审 → ③ 编写测试代码/脚本

## 目录结构

```
manual-tests/
├── README.md              # 本文件，模板
├── <test-name>/           # 每个测试一个子目录
│   ├── README.md          # 测试说明（从下方模板复制）
│   ├── script.sh          # 测试脚本（可选）
│   └── notes.md           # 执行记录/问题（可选）
└── ...
```

---

## 测试模板（复制到新测试目录的 README.md）

```markdown
# <测试名称>

## 目的

<!-- 为什么需要这个手动测试？覆盖什么场景？ -->

## 前置条件

- [ ] <!-- 例: 服务已启动，P2P 已启用 -->
- [ ] <!-- 例: 需要两个节点在线 -->

## 测试步骤

1. <!-- 操作描述 -->
2. <!-- 操作描述 -->
3. <!-- ... -->

## 预期结果

<!-- 期望看到什么行为 -->

## 实际结果

<!-- 执行后填写 -->

| 步骤 | 通过 | 备注 |
|------|------|------|
| 1    | Y/N  |      |
| 2    | Y/N  |      |
| ...  | Y/N  |      |

## 生成的测试代码

<!-- 手动测试验证通过后，放入对应的自动化测试文件或脚本 -->
```
