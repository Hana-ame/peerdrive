⚙️ 高级信令服务器参数与连接说明（默认已预置官方信令，通常无需修改）
自托管信令填节点启动时用的 PEERDRIVE_PEERJS_*，并取消勾选 wss（多为 ws://）。 也可以用链接直接带参数：?node=<id>&host=&port=&secure=0
自动搜索：向上面这个信令问「现在有哪些节点在线」（信令 REST GET /discover/nodes）， 结果出现在左栏「在线节点」。这一步是跨域请求，信令没给 Access-Control-Allow-Origin 时浏览器会把它连状态码一起吞掉——失败信息里会点名这件事。
预共享密钥：节点用 PEERDRIVE_PSK 开了门禁时才需要—— 连上后如果提示 psk required，说明你没填或填错了。 密钥不会被写回地址栏、也不会存进「最近连接」，只留在这一页的输入框里。
信令 token：信令用 peersignal --tokens（或 PEERJS_TOKENS） 开了注册白名单时才需要——留空则本面板不发送该字段（走 peerjs 默认随机 token， 与未开启白名单时的旧行为一致）。填错/没填的表现是握手直接被拒（bad handshake）， 因为白名单在 HTTP 升级层拦截，拿不到更细的报错。此字段与预共享密钥同待遇： 不回写地址栏、不存「最近连接」。
我的节点 id（右上角）：固定不变，存在这台浏览器里。节点运营者要把它填进 好友名单，你才拿得到 private 级别的内容 —— id 每次都随机的话， 名单等于没填。
分享链接：清单每行都有「链接」按钮，生成一条 ?node=&hash= 的链接，对应 unlisted 级别： 内容不出现在清单里，但拿到链接的人凭 hash 取得到。链接同样不含密钥。

📤 向当前节点投递文件 / 远程 URL 离线入库（写操作 · 展开使用）
走协议的 upload 动词：内容按 64KB 分片、由节点说了算节奏（它回一片授权才发下一片）， 入库成功后节点返回内容的 sha256——这就是之后能按它取回的地址。 同一个 chrome/Safari 标签页里不要同时往一个节点传两个文件：一条连接上同时只能有一个上传流。
走协议的 pull 动词：让节点替你去抓这个地址并入库，适合你手上只有链接、 或内容在大网另一端的场景。节点侧有 SSRF 防护——只接受公网 http/https， 内网/本机地址、带用户名密码的 URL、跳到内网的重定向都会被拒，也都有大小上限。 这类拒绝是预期行为，错误信息按原话透传。
⚠️ 入库是写操作：节点开了 PSK 门禁时必须先在上面填对密钥，否则会被回 PSK_REQUIRED；节点没开共享写入、磁盘满或被限流时也会直接回错误。
