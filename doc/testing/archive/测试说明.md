## 2. E2E 测试 `test/e2e-all.sh`

**运行**（无需提前启动任何服务）：
```bash
cd go
bash test/e2e-all.sh
```

**测试 12 个段，85 条断言**：

| # | 段 | 端点 | 断言数 | 测试内容 |
|---|-----|------|--------|----------|
| 1 | Health | `GET /ping` | 2 | 服务启动、返回 pong |
| 2 | File Upload | `POST /files/upload` | 10 | 新文件 201、响应含 hash+size、on-disk 存储路径验证、重复上传 200 already_exists、相同 hash、第二个不同文件 |
| 3 | File Verify | `GET /files/verify/:hash` | 3 | 合法 hash 返回元数据、无效 hash 返回 400 |
| 4 | SHA256 Download | `GET /sha256sum/:hash` | 3 | 下载 200、文件 diff 一致、无效 hash 404 |
| 5 | Register Local | `POST /files/register_local` | 5 | 注册返回 hash、响应含 filename、verify 验证、重复注册返回相同 hash、下载文件一致 |
| 6 | Register Folder | `POST /files/register_folder` | 2 | 返回有效 JSON、注册文件数 ≥1 |
| 7 | Anonymous Collections | 多个 | 22 | 创建 201、路径穿越拒绝 400、friendly_name、GET 合集 JSON(version=1)、通过 sha256sum 下载合集、entries 下载对比原文件(2 条目)、Fork 201→不同 hash→条目过滤、**Commit 201→不同 hash→新条目→version=2**、不存在合集 404 |
| 8 | Named Collections | 多个 | 22 | 创建→重复拒绝 409、列出/获取合集、添加条目×2、删除条目→验证已移除、下载合集文件、Commit→version_number+snapshot_hash、版本日志、第二次 commit、rollback→验证条目还原 |
| 9 | Fork/Merge/Pull | `POST /actions/*` | 4 | Fork 创建新合集→验证条目、Merge 合并成功、Pull 返回响应 |
| 10 | File Delete | `DELETE /files/:hash` | 2 | 删除成功、verify 返回 404 |
| 11 | Tasks | `GET /tasks` | 2 | 任务列表有效、不存在任务返回 404 |
| 12 | Edge Cases | 多个 | 5 | 不存在用户、空合集创建、无效 hash 条目→400、非法 body→非 200 |

预期输出：`PASS: 84  FAIL: 0  WARN: 1  TOTAL: 85`

> WARN: 空 body `{}` 创建 collection 返回 200（边界行为），不影响功能。

```bash
cd go && PORT=3000 PEERDRIVE_P2P_ENABLE=false PEERDRIVE_STORAGE=./storage go run ./cmd/server/main.go

# 终端 2
cd go && bash test.sh
```

最早写的全端点集成测试，依赖已在 3000 端口运行的 server。测试内容与 e2e-all.sh 重叠，但缺少一些新端点。如果已有 e2e-all.sh 建议用后者。

## 4. 上传测试 `test/upload.sh`

**运行**（需 server 在 3000）：
```bash
bash test/upload.sh
```

3 个测试：
1. **新文件上传** — 上传文本文件，验证 HTTP 201 + hash + size + 文件存在磁盘 + 下载内容一致
2. **重复上传** — 验证 HTTP 200 + `already_exists: true` + same hash
3. **第二个文件** — 验证 HTTP 201 + 不同 hash + 下载一致

---

## 5. 文件注册测试 `test/register.sh`

**运行**（需 server 在 3000）：
```bash
bash test/register.sh
```

3 个测试：
1. **注册单个文件** — `POST /files/register_local`，验证返回 hash + verify 匹配本地 sha256 + size 一致 + 下载一致
2. **文件夹注册** — `POST /files/register_folder` 递归注册，验证每个返回的 hash 都可下载并匹配源文件
3. **重复注册** — 两次注册同一文件，验证返回相同 hash（content-addressed idempotency）

---

## 6. 匿名合集测试 `test/anon-collection.sh`

**运行**（需 server 在 3000）：
```bash
bash test/anon-collection.sh
```

6 个测试：
1. **创建合集** — 注册 2 个文件 → `POST /anon/collections`，验证 201 + hash
2. **路径穿越拒绝** — entries 含 `../etc/passwd` → 400
3. **获取合集 JSON** — 验证 version=1 + entries 结构
4. **sha256sum 下载** — 通过合集 hash 下载 JSON → 验证非空
5. **下载 entries 文件** — 下载合集内文件 → 内容与原始一致
6. **Fork** — Fork 合集（移除一个条目），验证新 hash 且条目数正确

## 7. P2P 双节点测试 `test/p2p.sh`

**运行**（自包含，无需提前启动服务）：
```bash
cd go
bash test/p2p.sh
```

2 个节点（A 端口 3001，B 端口 3002），测试 13 步：
1. Node A ping → `"pong"`
2. Node B ping → `"pong"`
3. P2P status → `enabled: true`
4. Node info → 非空 peer_id
5. mDNS 10 秒发现（软断言，WARN 不 FAIL）
6. Node A 注册文件
7. Node A 创建匿名合集
8. Node A 宣告 hash
9. Node B 手动 connect 到 A
10. Peer list 检查（至少一方看到对方）
11. Node B p2p/fetch 获取 A 的合集
12. p2p/sync 同步 → count > 0
13. p2p/push 推送（无强断言）

环境变量：`PEERDRIVE_P2P_ENABLE=true` `PEERDRIVE_MDNS_ENABLE=true` `PEERDRIVE_RELAY_ENABLE=false`

## 8. Relay 穿透测试 `test/relay.sh`

**运行**（自包含）：
```bash
cd go
bash test/relay.sh
```

2 个节点（Relay 端口 3001，Client 端口 3002），测试 12 步：
1. Relay 节点 ping → `"pong"`
2. Relay P2P status → `relay_mode: server`
3. Client ping → `"pong"`
4. Client P2P status → `hole_punch: true`
5. mDNS 发现（软断言）
6. Client 手动 connect 到 Relay
7. Peer list 检查（至少一方看到对方）
8. Client 注册文件 + 创建合集 + 宣告
9. Relay p2p/fetch 获取合集
10. Relay WS info 端点查询
11. Client request-file 广播文件请求
12. 无强断言，靠日志判断

环境变量：`PEERDRIVE_RELAY_ENABLE=true` `PEERDRIVE_RELAY_MODE=server/client` `PEERDRIVE_HOLE_PUNCH=true` `PEERDRIVE_AUTO_NAT=true`

## 运行全部测试（推荐顺序）

```bash
# 1. 单元测试 → 最快，无需 server
cd go && go test ./... -count=1

# 2. E2E 测试 → 完整覆盖所有 HTTP 端点
bash test/e2e-all.sh

# 3. 开发环境集成测试（先启动 server）
PORT=3000 PEERDRIVE_STORAGE=./storage PEERDRIVE_P2P_ENABLE=false go run ./cmd/server/main.go &
bash test/upload.sh && bash test/register.sh && bash test/anon-collection.sh

# 4. P2P 测试（需要 libp2p 环境）
bash test/p2p.sh
bash test/relay.sh
```

> 所有 bash 测试脚本中包含脚本顶部注释描述。`test/*.sh`（除 e2e-all.sh）均使用 `curl -x ""` 绕过系统代理。
