## 3. 连接对总表（每对一份文档）

> **💡 控制流 (Control Stream) 与 数据流 (Data Stream) 的架构解耦原则**：
> - **🕹️ 控制流（信令与管理面）**：传输指令、握手协商 (SDP/ICE)、心跳、房间哈希与 SQL 元数据。体量极小（字节~几KB），负责寻址建连与准入门禁，绝不承载大文件，保护信令服不被大流量冲垮；且危险的管理面指令**仅限本地 WS 会话**，WebRTC 不实现管理 verb。
> - **🚚 数据流（P2P传输与持久化面）**：传输真实文件二进制块 (64KB Chunk)。两节点建连后脱离信令全速点对点 P2P 传输，内置 4MB 动态背压流控防止内存溢出，边收边算增量 SHA-256 防篡改，SafeWrite 原子落盘。

|---|--------|----------|----------|--------------------------------|------|

## 4. 启动时序（服务端接线顺序）

来源于 `back/cmd/server/main.go`（`InitDB → PeerJSService.Start → 注册 source → SetupRouter`）：

```text
main()
├─ config.Load() + config.Validate()          # 01 config：读 env，配错直接 Fatalf
├─ checkUnsafeRoots / warnUnsupportedRoots    # 03 storage 相关：卷根拒绝 / os.Root 能力自检
├─ repository.InitDB(cfg.DBPath)              # 02 repository：SQLite 开库+迁移；defer CloseDB
│   └─ repository.SetAnonStorageDir(storageDir)#   匿名存储与普通文件同目录
├─ transport.NewPeerJSService(cfg, storageDir) # 09 transport：PeerJS 服务组装（cfg.PeerJSEnable 时）
│   ├─ FileIndex().AddReadRoot(storageDir + cfg.ShareDirs)  # 可读根登记（登记侧≠读取侧，缺了会 read failed）
│   └─ peerjsSvc.Start()                       # 10 peerjs 引擎启动（信令拨号等）
│   ├─ service.NewNodeDirectory(...) + SetSelfID/SetConnected/SetDial
│   │   └─ peerjsSvc.SetExtraPeers(nodeDir.JoinedPeerIDs)    # 节点市场 M1
│   ├─ service.NewNodeShare(cfg, storageDir)   # 共享范围 M2：storageDir/share_scope.json 持久化
│   │   ├─ share.SetDirHook(dirs → FileIndex().AddReadRoot)  # 运行时新增共享目录补登记
│   │   ├─ SetAnonAccess / SetFileLister / SetFileInfoReader
│   │   ├─ peerjsSvc.SetShareProvider(share.SnapshotFor) / SetShareGate(share)
│   │   └─ nodeDir.SetShareSummary(share.Summary)
│   ├─ service.NewPeerPuller(cfg.DownloadDir)  # 跨节点拉取 M3：SetSource(peerjsSvc) + FileAccess
│   ├─ source.New() + Register(local/peer/url) # 07 source：本地→peer→URL 模板顺序
│   │   └─ router.SetSourceManager(mgr) / peerjsSvc.SetFileRouter(mgr)  # serveFile 多源路由
│   └─ SetForwardRules(PEERDRIVE_FORWARD_RULES) # 端口转发 v2 规则
├─ router.SetRegServer / SetPeerJSService / SetPeerJSConfig / SetNodeDirectory / SetNodeShare / SetPeerPuller
└─ router.SetupRouter(cfg)                     # 04 router：注册全部 HTTP 路由（必须在上列 Set* 之后）
    └─ http.Server（ReadHeaderTimeout=15s）— ListenAndServe
```

要点：

- **注入顺序敏感**：`SetPeerJSService` / `SetNodeDirectory` / `SetSourceManager` 必须在 `SetupRouter` 之前（路由注册时读取这些句柄）；注释明确点名。
- **共享范围跨重启**：`service.NodeShare` 运行时改动落在 `storageDir/share_scope.json`（`如何储存/何时储存`见 [06-service.md](modules/06-service.md) 与 [06-service-transport.md](connections/06-service-transport.md)）。
- **可读根双轨制**：`AddReadRoot` 登记「对外可读的根」——启动批来自 `cfg.ShareDirs`，运行时新增由 `share.SetDirHook` 补。

## 5. 停机时序

```text
SIGINT/SIGTERM → srv.Shutdown(ctx, 20s)   # 先停接收新请求，给进行中请求 20s 收尾
   ├─ 超时 → srv.Close() 强制关闭          # 不能无限拖住停机（容器编排会 SIGKILL）
   └─ peerjsSvc.Close()  +  repository.CloseDB()  # defer 链在 main 返回时执行
```

坑：不能用 `r.Run()`（内部 Fatalf 直接 os.Exit，defer 不执行 → Windows 上 SQLite 句柄不关，下次启动可能打不开库；大文件传输被掐断）。

## 6. 运行时典型主流程

### 6.1 管理面操作（前端点按钮 → 后端执行）

```
frontend 页面 → ws.js（本地 WS /ws/peer）
  → admin verb: {"type":"admin","method","path","body","token","reqId"}
  → 09 transport admin.go：连接级 expect 状态机 → 内部转发 gin engine
  → 04 router → 05 controller → 06 service → 02 repository / 07 source / 09 transport
  ← admin-resp {status, body, reqId}（status≥400 → 前端 reject）
```

- 关键规定：管理面**只走本地 WS**；peerjs/WebRTC 不实现管理 verb（防权限面漏洞）。
- 二进制上传/下载：admin-bin 声明头 + 二进制帧原子连续（`binaryExpect` 单槽路由）。
- 细节：[01-frontend-backend.md](connections/01-frontend-backend.md)、[02-router-controller.md](connections/02-router-controller.md)。

### 6.2 文件登记/上传（写入侧）

```
HTTP/WS 上传 → 05 controller（file/anon）
  → 10 storage（safewrite + 内容寻址落盘：storage/<hash 前两位>/<hash>）
  → 02 repository 记元数据（sha256→路径，file_index 等表）
  → 03 storage + 02 repository 两处一致后返回成功
```

### 6.3 P2P 拉取下载（对端 → 本节点落盘）

```
req 帧（发起方）→ 09 transport outbound → 10 peerjs 引擎 → 11 signalserver 转发
  → 对端 inbound：FileRouter（07 source.Manager）多源解析 → 命中本地/回源对端/URL
  ← data 帧分块回传（流控阈值控制）→ 11 transport-storage 落盘 + file_index 登记 + 哈希校验
```

- 数据面帧协议（req/meta/data/done/err + create/upload/list/info/delete/sync 索引 + fwd-* 转发）以 `doc/REFACTOR.md` §4 为准，`front/src/ws.js` 头注释有精确约定。
- 细节：[07-transport-peerjs.md](connections/07-transport-peerjs.md)、[08-transport-signalserver.md](connections/08-transport-signalserver.md)、[11-transport-storage.md](connections/11-transport-storage.md)。

### 6.4 共享提供（对端读我的文件）

```
对端 req 帧 → 本节点 inbound → ShareGate（06 service NodeShare：private 只给好友/自己）
  → SnapshotFor(请求者 id) 出共享清单 → FileRouter 按清单前缀过滤 → 回 frame
```
