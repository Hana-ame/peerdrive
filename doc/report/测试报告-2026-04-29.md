## 2. E2E 全端点测试 (85 断言, 自包含)

自包含测试：自动编译 → 启动服务(:3999) → 12 段测试 → 清理。

### 测试流程

| 段 | 端点 | 测什么 | 断言 |
|----|------|--------|------|
| 1 | `GET /ping` | 健康检查 | 2 |
| 2 | `POST /files/upload` | **文件上传**：新文件 201、重复 200 + already_exists、不同文件不同 hash、磁盘验证 | 10 |
| 3 | `GET /files/verify/:hash` | 文件校验：合法 hash 200、无效 hash 拒绝 | 3 |
| 4 | `GET /sha256sum/:hash` | SHA256 下载：内容一致性、无效 hash 404 | 3 |
| 5 | `POST /files/register_local` | 本地注册：hash 计算、重复幂等、下载验证 | 5 |
| 6 | `POST /files/register_folder` | 文件夹注册：目录遍历 | 2 |
| 7 | `POST/GET /anon/collections` | 匿名合集：创建、路径穿越拒绝、friendly_name、entries 下载、Fork、Commit、version 递增 | 22 |
| 8 | `POST/GET/DELETE /collections` | 命名合集：CRUD、条目增删、Commit、rollback、版本日志 | 22 |
| 9 | `POST /actions/fork|merge|pull` | Fork/Merge/Pull：条目复制、策略合并 | 4 |
| 10 | `DELETE /files/:hash` | 删除后 verify 404 | 2 |
| 11 | `GET /tasks` | 任务列表 | 2 |
| 12 | Edge Cases | 不存在用户、空合集、无效 hash、非法 body | 5 |

### 运行方式

```bash
cd go && bash test/e2e-all.sh
```

### 上传测试详解（段 2）

```
1. 创建临时文件 → POST /files/upload → 期望 201 + hash + size
2. 磁盘验证 → storage/{hash[:2]}/{hash} 存在
3. 重复上传同一文件 → 期望 200 + already_exists + 相同 hash
4. 上传第二个不同文件 → 期望 201 + 不同 hash
5. hash 不同 → 确认内容寻址正确
```
