## 📋 待开发

### 高优先级

- **分享令牌权限校验** — token 签名/过期/访问次数限制
- **转存（Pull）** — 根据分享信息拉取远端文件到本地存储
- **多节点 e2e 测试** — 集成测试脚本覆盖 Fork/Pull/冲突场景

### 中优先级

- **P2P 加密传输** — libp2p Noise 协议配置化
- **流量控制** — 带宽限制
- **WebRTC 浏览器直连** — 不依赖 libp2p 节点

### 低优先级

- 分享统计（访问次数/地理分布）
- 密码保护分享
- 过期自动清理分享链接
