# Peerdrive 操作说明

> 仓库: `github.com/Hana-ame/peerdrive`
> Go 分支: `feat/stage2-e2e-test` / React 分支: `frontend`

---

## 1. 克隆仓库

```bash
git clone git@github.com:Hana-ame/peerdrive
cd peerdrive
```

**注意**：Go 后端和 React 前端是**两个独立的 git 仓库**，分别 clone 到不同目录，用不同分支：

```bash
# Go 后端
git clone -b feat/stage2-e2e-test git@github.com:Hana-ame/peerdrive peerdrive-go
cd peerdrive-go

# React 前端（另一个目录）
git clone -b frontend git@github.com:Hana-ame/peerdrive peerdrive-react
cd peerdrive-react
```

---

## 2. 启动后端

```bash
cd peerdrive-go
go build -o peerdrive-server ./cmd/server/
PORT=3000 PEERDRIVE_STORAGE=./storage PEERDRIVE_P2P_ENABLE=false ./peerdrive-server
```

看到 `Listening and serving HTTP on :3000` 即启动成功。

验证：`curl --noproxy '*' http://localhost:3000/ping` 返回 `pong`

> 如果有 Privoxy 代理，所有 curl 需加 `--noproxy '*'` 或 `-x ""`

---

## 3. 运行 Go 单元测试

```bash
cd peerdrive-go
go test ./... -count=1
```

预期输出 5 个 `ok`（config / controller / model / repository / service），66 个测试全部通过。

---

## 4. 运行 E2E 测试

自包含脚本，自己 build + 启动 server + 清理：

```bash
cd peerdrive-go
bash test/e2e-all.sh
```

预期结果：
```
PASS: 84  FAIL: 0  WARN: 1  TOTAL: 85
All tests passed
```

唯一 WARN：空 body 创建 collection 返回 200（边界行为差异），无影响。

脚本工作流程：
1. 在 `/tmp/peerdrive_e2e_all/` 创建临时目录
2. `go build` 编译最新版本
3. 端口 3999 启动 server（P2P 关闭）
4. 按序测试 12 个段共 85 条断言
5. trap 自动清理（杀进程 + 删临时文件 + 删 peerdrive.db）

---

## 5. 启动前端

```bash
cd peerdrive-react
npm install        # 首次需要
npm run dev
```

访问 `http://localhost:5173`

页面导航：
- `/` — Plaza 广场：列出合集、搜索、新建
- `/:user/:coll` — Explorer 资源管理器：上传文件、Commit、Merge、版本历史、本地同步
- `/anon/create` — 创建匿名合集
- `/anon` — 匿名合集浏览器：浏览、Fork、**Commit**

前端 API 地址在 `src/api.js` 第 1 行硬编码为 `https://wsl-3000.moonchan.xyz`，本地开发时需改成 `http://localhost:3000`。

## 8. 环境变量速查

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `PORT` | `3000` | HTTP 端口 |
| `PEERDRIVE_STORAGE` | `./storage` | 文件存储目录 |
| `PEERDRIVE_P2P_ENABLE` | `true` | 启动 P2P |
| `PEERDRIVE_P2P_LISTEN` | `/ip4/0.0.0.0/tcp/0` | P2P 监听地址 |
| `PEERDRIVE_MDNS_ENABLE` | `true` | mDNS 局域网发现 |

DB 固定为工作目录下的 `peerdrive.db`。

## 9. 常见问题

**Q: curl 报 Privoxy 错误**  
A: 加 `--noproxy '*'` 或 `export no_proxy='*'`

**Q: E2E 测试报 "Server failed to start"**  
A: 确认端口 3999 没有被占用：`fuser -k 3999/tcp`

**Q: 前端页面 API 报 404**  
A: 检查 `src/api.js` 第 1 行的 `API_BASE` 是否指向正确的后端地址

**Q: 前端报模块找不到**  
A: 运行 `npm install` 安装依赖

**Q: Go build 失败**  
A: 确认有 Go 1.21+ 且网络能访问 GitHub（下载 go mod 依赖）
